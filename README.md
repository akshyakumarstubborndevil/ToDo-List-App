# ToDo-List-App
A simple Android To-Do List App built using Java and Android Studio with add, edit, and delete task features.

ToDo List App

A simple Android To-Do List application developed using Android Studio and Java.

Features:
• Add Tasks
• Edit Tasks by tapping on them
• Delete Tasks using long press
• Simple and User-Friendly UI
• Voice/Mic-based Task Input Support
• Real-time Task Updates

Tools & Technologies:
• Android Studio
• Java
• XML
• Android Emulator
